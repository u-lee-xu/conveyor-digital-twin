# 数字孪生用户端网关程序设计

## 1. 概述

### 1.1 软件定位

用户端网关程序是一个运行在用户本地的桥接软件，负责将PLC的ModbusTCP信号转换为MQTT消息，实现与数字孪生平台的通信。

### 1.2 适用场景

| 模式 | 场景 | 数据流向 |
|------|------|----------|
| 同步模式 | 用户有真实设备 | 真实设备 → PLC → 网关 → MQTT → 数字孪生显示 |
| 仿真模式 | 用户只有PLC（无实物设备） | PLC控制 → 网关 → MQTT → 数字孪生执行 → 反馈 → PLC |

## 5. 工作模式详解

### 5.1 同步模式

**用途**：真实设备与数字孪生同步显示

**数据流**：
```
┌─────────┐    ModbusTCP    ┌─────────┐     MQTT      ┌─────────────┐
│真实设备  │───────────────►│   PLC   │──────────────►│   网关程序   │
│传感器等 │                 │         │               │             │
└─────────┘                 └─────────┘               └──────┬──────┘
                                                              │
                                                              │ MQTT
                                                              ▼
                                                      ┌─────────────┐
                                                      │  数字孪生   │
                                                      │  (显示同步) │
                                                      └─────────────┘
```

**处理逻辑**：
1. 周期读取PLC离散输入（传感器、磁性开关）
2. 检测状态变化
3. 状态变化时发布MQTT消息
4. 数字孪生订阅并更新显示

**读取周期**：100ms（可配置）

### 5.2 仿真模式

**用途**：PLC控制虚拟产线，用于程序调试

**数据流**：
```
                              控制信号
┌─────────┐    ModbusTCP    ┌─────────┐     MQTT      ┌─────────────┐
│   PLC   │◄───────────────►│ 网关程序 │──────────────►│  数字孪生   │
│         │   读线圈/写寄存器│         │               │ (虚拟产线)  │
└─────────┘                 └─────────┘               └──────┬──────┘
     ▲                                                     │
     │                                                     │
     │                    反馈信号                          │
     └─────────────────────────────────────────────────────┘
```

**处理逻辑**：

**方向1：PLC → 数字孪生（控制）**
1. 周期读取PLC线圈状态（控制信号）
2. 检测状态变化
3. 发布控制消息到MQTT
4. 数字孪生执行对应动作

**方向2：数字孪生 → PLC（反馈）**
1. 订阅MQTT反馈主题
2. 收到反馈消息
3. 写入PLC离散输入寄存器
4. PLC读取反馈状态

## 8. 使用流程

### 8.1 同步模式使用流程

```
1. 启动网关程序
2. 配置PLC地址和MQTT Broker
3. 从数字孪生平台获取用户ID
4. 选择"同步模式"
5. 点击"启动"
6. 网关开始读取PLC传感器状态
7. 状态变化时发布到MQTT
8. 数字孪生平台实时显示设备状态
```

### 8.2 仿真模式使用流程

```
1. 启动网关程序
2. 配置PLC地址和MQTT Broker
3. 从数字孪生平台获取用户ID
4. 选择"仿真模式"
5. 点击"启动"
6. PLC控制信号通过网关发送到数字孪生
7. 数字孪生执行动作并反馈状态
8. 网关将反馈写入PLC
9. PLC程序读取反馈进行逻辑控制
```
