## 1. 一句话目标

自动配药场景：三维数字孪生被控对象（滑块料斗往返 + 三药仓气动送药 + 末端翻转取药），配合 PLC 仿真软件/实体 PLC 调试使用。四模式：手动 / 演示 / 仿真 / 评分（评分暂缓开通）。

## 2. 设备清单与功能

| 设备 | 数量 | 说明 |

## 3. 工艺流程

自动模式配方循环：
1. 面板配方设定区输入配方（A/B/C 各 0~9 份，0=不取；启动后锁定）
2. 启动按钮 → 料斗按配方顺序逐仓取药：到达药仓位停 → 伸缸推 1 粒 → 缩缸 → 按份数重复 → 下一仓
3. 全部取完 → 到终点限位 → 翻转倒药（盛药/翻转双磁性开关反馈）→ 回起点待命
4. 取药仓有药 → 黄灯"请取药" → 人工取药 → 按取药确认按钮 → 自动跑下一轮（循环）
5. 空仓（演示模式）：红灯闪提示 + 自动补药（模拟人工），流程不中断；空仓传感器常开，PLC 不用则忽略
6. 停止：暂停当前步骤；复位：回原点并清状态

手动模式（平台模式，不经 PLC）：电机正/反转点动、3 送药缸伸/退、翻转缸翻转/复位、灯塔单灯亮灭；传感器实时响应显示。

仿真模式：3D 场景 + 面板按钮/开关/指示灯经双向网关（8081）连接 PLC 仿真软件或实体 PLC，全部信号有地址。

评分模式：**暂不开通**（保留扩展位，参考 coal-sorting 评分面板机制后续可加）。

## 4. PLC 点位 / 控制逻辑

- 遵循平台惯例：`mock-addresses.js` 单一地址来源 + 3 协议映射（Modbus TCP / S7 / 三菱）+ `--check` 一致性校验
- 输入点：启动 / 停止 / 复位 / 急停 / 取药确认；送药缸前后磁性开关 ×3×2；翻转缸盛药/翻转磁性开关 ×2；起始/终点限位 ×2；空仓 ×3；取药仓有药 ×1；编码器（位置寄存器）
- 输出点：电机正/反转；送药缸伸出 ×3；翻转缸翻转；灯塔 绿/黄/红（含"请取药"黄灯提示）
- 手自动模式开关为平台模式信号，地址表保留占位；具体地址分配：建模后按寄存器区间填写（先入 `mock-addresses.js` 再实现）

## 5. 场景布局与外观

- 传动轴沿 X 轴，两端支架；料斗滑台往返
- A/B/C 药仓均匀分布在轴上方（Y 高位，正上方或侧上方均可），送药气缸横向推出药粒入料斗（参考场景1气缸位）
- **药仓出药结构（关键约束）**：药仓为**竖直/倾斜堆叠通道**（药片像弹夹堆叠），一端为推药气缸（推杆从底部/侧部伸出推最底层 1 粒），另一端出药口正对下方取药料斗；**气缸缩回时上方药片重力下落填补 1 粒位移**，保证下次伸出仍推 1 粒
- 起点限位在左端（原点），取药仓在右端（终点限位 + 翻转位 + 编码器同侧）
- 底架 + 控制柜（3 按钮/急停/指示灯）+ 灯塔立杆（起点端）
- 药品表现：小圆柱（药片），每份 1 粒，A/B/C 三色区分；气缸推出→滑落入料斗→翻转堆进取药仓→人工取走清空
