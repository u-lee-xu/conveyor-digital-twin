## 三、关键碰撞关系分析

### 上料气缸推板 vs 物料（初始状态）

```
物料 Z 范围: 0.51 ~ 0.69  (中心0.6, 半径0.09)
推板 Z 范围: 0.72 ~ 0.84  (中心0.78, 半径0.06)
间隙: 0.72 - 0.69 = 0.03  ← 很小！可能视觉上看起来重合
```

### 物料台台面 vs 传送带表面

```
物料台台面 Y: 0.955 ~ 1.005  (中心0.98, 半径0.025)
传送带表面 Y: 0.96 ~ 1.0     (中心0.98, 半径0.02)
基本齐平，但物料台略高0.005
```

### 物料初始 Y 位置 vs 台面

```
物料中心 Y: 1.06
物料底部 Y: 1.06 - 0.09 = 0.97
台面顶部 Y: 1.005
间隙: 0.97 - 1.005 = -0.035  ← 物料底部嵌入台面0.035！
```

## 四、需要调整的参数建议

### 问题1: 物料初始Y位置偏低，嵌入台面

- **文件**: constants.ts 第 96 行
- **当前**: `[-1.3, 1.06, 0.6]`
- **建议**: Y 改为 `1.10` 或更高，让物料底部在台面之上

### 问题2: 推板碰撞体和物料初始间隙太小

- **文件**: PhysicsScene.tsx 第 25 行
- **当前**: 缩回时 `z += 0.08`
- **建议**: 改为 `z += 0.15` 或更大，让推板远离物料

### 问题3: 推板碰撞体厚度

- **文件**: PhysicsScene.tsx 第 270 行
- **当前**: `args={[0.25, 0.15, 0.06]}`
- **建议**: Z方向0.06可能太薄导致穿模，可改为0.10

### 问题4: 推板Y偏移

- **文件**: PhysicsScene.tsx 第 204 行
- **当前**: `position[1] + 0.135`
- **建议**: 根据调试线框调整，确保推板碰撞体和物料碰撞体在同一高度

### 问题5: 推板移动速度

- **文件**: PhysicsScene.tsx 第 175 行
- **当前**: `diff * 0.08`
- **建议**: 太慢可能不像气缸，太快可能穿模，0.08~0.15之间调整

## 五、调试技巧

1. 开启调试: PhysicsScene.tsx 第 457 行 `showDebug = true` 可看到所有碰撞体线框
2. 彩色线框就是碰撞体，绿色=sensor，其他颜色=碰撞体
3. 修改后 HMR 自动更新，不需要重启
4. 调试完成后记得 `showDebug = false`
