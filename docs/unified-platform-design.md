# 多设备统一平台 · 功能设计方案

## 一、产品定位

- **用户**：老师 + 学生（学生为主），不做现场调试、不做复杂管理
- **形态**：Electron Windows 桌面版为主，网页版仅开发用
- **教学闭环**：学生外部写 PLC 程序 → 仿真联调 → 评分评测 → 演示讲解
- **目标**：一个应用装多套设备，学生换设备零学习成本

## 二、总体架构

- **平台壳**（共享层，统一逻辑）：启动页、统一模式框架、连接管理、统一评分引擎、演示工具、统一视觉规范
- **设备插件**：每设备注册——设备名/图标、协议、实现哪些模式、3D 场景入口、PLC 点表↔归一化设备状态映射、评分规则表
- **协议**：Modbus TCP / Siemens S7 / 三菱 MX，统一由连接管理承载
- **视觉**：一套 UI 规范，设备差异仅在 3D 场景内容

## 三、核心功能

1. **选页式入口**：设备选择启动页（纯启动器）→ 设备工作区，可返回切换
2. **统一模式框架**：仿真（内部模拟联调）/ 评分（跑学生程序评测）/ 演示（教学讲解），+ 设备特有操作模式；设备缺省模式不显示
3. **连接管理**：设备工作区内设置连接参数（协议/IP/端口），默认=本地仿真器（127.0.0.1），开箱即用，记住上次配置
4. **统一评分引擎**：平台通用引擎 + 每设备规则表（数据驱动），规则写在归一化状态上；常规点用规则表，特殊工艺用设备自定义评分函数逃逸；成绩单格式统一
5. **演示模式**：运行动画 + 讲解工具（暂停/单步/复位 + 传感器/执行器高亮标注），纯演示脚本驱动，与 PLC 无关
6. **老师自定义**：仅开放评分规则导入/导出 + 权重编辑（简单表格），其余纯开发维护

## 四、落地路径（三阶段，每步可运行）

1. **搭壳接入 conveyor**：启动页 + 统一模式框架 + 连接管理，跑通最小闭环
2. **合并 pneumatic 分支**（feature/pneumatic-mitsubishi + feature/multi-protocol）接入壳，验证三菱协议接入方式
3. **接入 coal-sorting**（Phase1）
