A 类　面板与菜单（5 项）

实验 1　三级菜单读写参数 ｜ 手动 模式

目的　掌握真机式 L1 参数组 → L2 参数 → L3 设定值的编辑、保存与放弃。

步骤

  1. 设备列表进入「MD520 变频器」，保持手动模式。
  2. 按 PRG 进一级菜单，用递增键切到 F0 组，OK 进二级，选 F0-08 后 OK 进三级。
  3. 左右键选闪烁位，上下键把预置频率从 50Hz 改成 30Hz。
  4. OK 保存（自动跳到下一个参数）；再改一次后用 PRG 放弃，对比两次结果。

预期现象　保存后主显 30.00、状态行显示下一个参数码；PRG 放弃则回到修改前的值。参数标「停机更改」时运行中改不了。

观察窗口　主/辅显示区、闪烁位、状态行 L1/L2/L3

易错点　闪烁位用左右键，数值用上下键；不要按菜单键退出（那是切菜单）。

实验 2　四种菜单与主辅显示区 ｜ 手动 模式

目的　区分 basic / user / changed / fault 四种菜单，掌握菜单键点按与长按。

步骤

  1. 点按菜单键循环四种菜单，观察 basic 与 user 的参数条数。
  2. 先改几个参数，再切到 changed，确认只列出改过出厂值的参数。
  3. 长按菜单键 600ms 切主/辅显示区；切到 fault 看故障列表。

预期现象　basic 显示全部 39 个参数；user 默认 4 项；changed 只列偏离默认值的码；fault 显示 6 条教学故障码。

观察窗口　辅显示区代码、菜单指示灯

易错点　长按必须超过 600ms，短按只切菜单。

实验 3　面板 RUN/STOP 与预置频率 ｜ 手动 模式

目的　理解面板命令源与加减速斜坡，建立频率与 3D 转速的对应关系。

步骤

  1. 确认 F0-02=0（操作面板）、F0-03=0（数字设定）、F0-08 = 50Hz、F0-17 = 20s。
  2. 按 RUN，每 1 秒记录一次输出频率；到稳态后按 STOP。
  3. 把 F0-17 改成 2s，复位后重做一次。

预期现象　默认 20s 斜坡下 1 秒约升 2.5Hz、约 20 秒到 50Hz；改成 2s 后 1 秒约升 25Hz。3D 风扇、双滚筒、皮带条纹与频率牌同步。

观察窗口　主显输出频率、3D 风扇转速、皮带条纹位移

易错点　斜坡时间是从 0 到最大频率的时间，不是到目标频率的时间。

实验 4　参数初始化 FP-01 六档 ｜ 手动 模式

目的　分辨恢复出厂、保留电机铭牌、清记录与备份用户参数的差别。

步骤

  1. 先把 F1-05 从 1460rpm 改成 2000rpm，并制造一条故障记录。
  2. 依次试 FP-01=1、2、4、501、503，每次记录 F1-05 与故障列表。

预期现象　=1 时 F1 铭牌保持 2000rpm；=2 只清故障记录、参数不动；=503 全部回出厂（F1-05=1460）；=4 / 501 为备份/恢复用户参数（教学镜像）。

观察窗口　参数菜单、fault 菜单

易错点　FP-01 是「停机更改」，运行中改不了；0=无操作。

实验 5　FP-02 掩码控制自定义菜单 ｜ 手动 模式

目的　理解功能参数组显示选择对菜单的影响，以及基本菜单不受影响。

步骤

  1. 记下 user 菜单默认 4 项（F0-02、F0-08、F0-17、F0-18）。
  2. 把 FP-02 设 0，回 user 菜单；再设 63、1023 各看一次。
  3. 每次都切回 basic 对照。

预期现象　FP-02=0 → user 菜单空；=63（默认）→ 4 项；basic 始终是 39 个参数，索引不变。

观察窗口　user / basic 菜单条数

易错点　低 10 位按组顺序掩码；只作用 user 菜单，别误以为整个参数表被隐藏。

B 类　给定与频率（7 项）

实验 6　四种给定切换 ｜ 手动 + 仿真 模式

目的　分辨命令源 F0-02 与频率源 F0-03，理解谁能抢运行权。

步骤

  1. 依次设 F0-02=0/1/2，观察面板 RUN 是否生效。
  2. 固定 F0-02=0，依次设 F0-03=0/2/3/6/9，观察目标频率从哪来。

预期现象　F0-02=2（通信）时面板 RUN/STOP 不再抢运行权，由 2000H 控制字决定；F0-03=6 走 DI 多段速、=9 走通信给定。

观察窗口　485 状态行 2000H 命令、运行/停机徽标

易错点　命令源与频率源是两个独立参数，不要一起改。

实验 7　DI 多段速 8 段 ｜ 手动 模式

目的　掌握 DI1~DI3 三位二进制选段 + DI4 运行使能。

步骤

  1. 设 F0-02=1、F0-03=6；教学信号区按 DI4 使能。
  2. 按 DI1~DI3 组合出 000~111，逐段记录「段N xxHz」。

预期现象　默认 FC 百分比 0/20/40/60/80/100/70/50% 对应 0/10/20/30/40/50/35/25Hz（F0-10=50Hz）。

观察窗口　段速标签、面板输出频率、3D 转速

易错点　DI4 不使能时不会运行；DI5 是高速脉冲输入，不参与选段。

实验 8　FC 段速成为真值 ｜ 手动 模式

目的　验证段速不是硬编码 Hz 表，而是 FC 百分比 × F0-10。

步骤

  1. 停在段 2（DI2 单独 ON），记下频率。
  2. 把 FC-02 从 40% 改成 10%，保存后回到监控页。
  3. 再把 F0-10 从 50 改成 60，看同一段的变化。

预期现象　FC-02=40% → 20Hz；改成 10% → 5Hz；F0-10=60 后 10% → 6Hz。面板、PLC 参考程序、3D 读数同源。

观察窗口　段速标签、1008H DI 位字、3D

易错点　FC 单位是相对最大频率的百分比，不是 Hz。

实验 9　AI 模拟量给定 ｜ 手动 模式

目的　理解 AI1 双极性电压、AI2 电压/电流拨码与频率映射。

步骤

  1. 设 F0-03=2，拖 AI1 从 0 到 5.0V，记录输出频率；再拖到 -5.0V。
  2. 设 F0-03=3，用「0~10V / 0~20mA」按钮切档，拖 AI2 到 5.0V 或 10mA。

预期现象　目标频率 = |AI| / 满量程 × F0-10：AI1 5.0V → 25Hz（取绝对值）；AI2 5.0V / 10mA → 25Hz。100AH 数值镜像同步。

观察窗口　AI1/AI2 滑块读数、100AH

易错点　AI1 是 -10~10V 双极性，负电压给的是频率绝对值；方向另由 FWD/REV 决定。

实验 10　485 通信给定与状态回读 ｜ 仿真 模式

目的　用控制字与频率给定控制变频器，并读懂回读状态。

步骤

  1. 设 F0-02=2、F0-03=9，连 MD520 虚拟 PLC :1507。
  2. PLC 侧写 2000H=1（正转）、7310H=3000（30.00Hz）、1000H=6000（60.00%）。
  3. 读 3000H、1001H、1009H、7044H。

预期现象　输出 30.00Hz；3000H=1（正转）、1001H=3000（0.01Hz）、1009H 的 DO1 位为 1；停机写 2000H=6 后 3000H=3。

观察窗口　485 只读状态行、:5087/status

易错点　2000H 没有 0 档，写 0 无意义；7310H 是 0.01Hz，1000H 是 ±100.00% 百分比。

实验 11　加减速时间与基准频率 ｜ 手动 模式

目的　对比 F0-17/18 与 F0-25 四档基准对斜坡速率的影响。

步骤

  1. 默认 F0-25=0，RUN 后记录 1 秒爬升量。
  2. 依次把 F0-25 设 1（同时 F0-08=30）、2、3（同时 F1-04=25），各跑 1 秒。
  3. 改 F0-18 观察停机回落。

预期现象　1 秒爬升量依次为 2.5 / 1.5 / 5 / 1.25Hz；F0-18 变小时回落明显加快。默认档 0 与旧行为一致。

观察窗口　主显输出频率、3D 转速

易错点　F0-25=1 的基准是「设定频率」，所以要先改 F0-08 才看得出差别。

实验 12　最大频率与控制方式 ｜ 手动 模式

目的　理解 F0-10 上限、FC 换算基准，以及 F0-01 三种控制方式的教学近似。

步骤

  1. 段 2（40%）下把 F0-10 从 50 改 60，记录频率。
  2. 把 F0-01 依次设 0(SVC)、1(FVC)、2(V/f)，各 RUN 1 秒记录爬升量。

预期现象　F0-10=60 后段 2 从 20Hz 变 24Hz；1 秒爬升 SVC 4.0Hz / FVC 3.13Hz / V/f 2.5Hz；FVC 频率到达灯容差更宽。

观察窗口　段速标签、FM 徽标、3D

易错点　这里只是低速段增益近似，没有真实矢量控制算法。

C 类　停机方向与状态（6 项）

实验 13　F6-10 三种停机方式 ｜ 手动 模式

目的　对比减速停机、自由停机、最大能力停机的曲线差异。

步骤

  1. 先 RUN 到 50Hz。
  2. 把 F6-10 依次设 0、1、2，每次从 50Hz 按 STOP，0.5 秒后记录输出频率。

预期现象　F6-10=0 约 48.75Hz（按 F0-18 减速）；=1 → 0Hz（立即断输出）；=2 约 43.75Hz（F0-18/5 强制斜坡）。

观察窗口　主显输出频率、3D 是否立即停转

易错点　自由停机不是「慢慢停」，是立刻断输出。

实验 14　F6-11~14 直流制动段 ｜ 手动 模式

目的　观察制动起始频率、等待时间、制动电流对自由停机过程的影响。

步骤

  1. 设 F6-10=1、F6-14=2（制动时间 2s），从 50Hz STOP，记录 0.3 秒频率。
  2. 把 F6-13 从 50% 改 100% 重做；再设 F6-11=20、F6-12=1 各做一次。

预期现象　F6-14>0 时自由停机不再瞬间归零，而是有制动减速段；F6-13=100% 比 50% 降得快；F6-12 拉长时间；F6-11 高于当前频率时不加制动增益。

观察窗口　主显输出频率、停机用时

易错点　这四个参数只在 F6-14>0 的制动段生效，默认 0/0/50 时行为与只看 F6-14 一致。

实验 15　F7-02 STOP/RESET 四档 ｜ 手动 模式

目的　理解 OFF1/OFF2/OFF3 对停机方式的覆盖。

步骤

  1. 保持 F6-10=0（减速停机），把 F7-02 依次设 0、1、2、3，各从 50Hz STOP。

预期现象　=0 沿用 F6-10 减速；=1(OFF1) 立刻自由停机；=2(OFF2) 最大能力停机；=3(OFF3) 减速停机。

观察窗口　输出频率回落曲线

易错点　F7-02 优先级高于 F6-10，排查停机异常时先看它。

实验 16　MF.K 五档功能 ｜ 手动 模式

目的　掌握 F7-01 五档分派与「仅操作面板命令源有效」的约束。

步骤

  1. F7-01 依次设 0、1、2、3、4，每档按一次 MF.K 观察。
  2. 把 F0-02 改成 2（通信）后，再试 F7-01=2/3/4。

预期现象　=0 无动作；=1 把命令源切回面板；=2 正反转切换；=3/4 正/反转点动（5Hz 上限）。F0-02≠0 时 2/3/4 全部无效。

观察窗口　FWD/REV 丝印、运行/停机、控制字

易错点　手册 285 页表 16-6：2、3、4 只在 F0-02=0 有效。

实验 17　正反转切换：减速到零再反向加速 ｜ 手动 模式

目的　验证换向不是瞬间反转，而是先按 F0-18 减速到 0、翻转输出方向、再按 F0-17 反向加速。

步骤

  1. 设 F7-01=2、F0-02=0，RUN 到有输出（建议先把 F0-18 / F0-17 改小到 2s 缩短等待）。
  2. 按 MF.K，立刻看 __dtVfdDrive：targetDirection 变 -1、direction 仍是 1、reversing=true、hz 持续下降。
  3. 连续采样直到 hz 归零、direction 翻成 -1，再看 hz 反向上升；随后间隔 0.5 秒采两次 fanAngle / beltPhase。

预期现象　换向期间电机仍按原方向转、只是越来越慢（减速阶段风扇角差仍为负）；频率归零后 direction 才由 1 变 -1 并反向加速；风扇角差由负变正（实测 -0.83 → +1.21），皮带相位由正变负（+0.023 → -0.034）；FWD/REV 丝印指令下达即互换。

观察窗口　__dtVfdDrive.direction / targetDirection / reversing / hz / fanAngle / beltPhase、FWD/REV 灯

易错点　别在减速阶段就断言反向：那时 direction 还是 1；面板丝印显示的是目标方向，3D 用的是实际输出方向 runDirection。

实验 18　DO 状态、故障与只读监视量 ｜ 手动 + 仿真 模式

目的　读懂 DO1/FM/RELAY、3000H 状态与输出电流/功率监视量。

步骤

  1. RUN 到稳态，看 DO1（运行中）、FM（频率到达）亮，RELAY 灭。
  2. 制造故障后看 RELAY 与 3000H=5，再用 STOP/RESET 或 2000H=7 复位。
  3. 把 F1-03 从 9A 改 18A、F1-01 从 3.7 改 7.4kW，看监视量；再设 F1-00=2（永磁同步）。

预期现象　满载时默认显示约 9.00A / 3.70kW；铭牌翻倍后约 18.00A / 7.40kW；F1-00=2 时电流 ×0.88；停机后监视量归零。

观察窗口　DO 只读徽标、data-dt-vfd-monitor、3000H / 7044H

易错点　这些监视量是教学近似（空载 15% 电流 + 负载率线性），不是真实电机模型。

D 类　外部 PLC 三协议（5 项）

实验 19　AutoShop / Modbus TCP 读写 ｜ 仿真 模式

目的　用 PLC 程序通过 coils 与 15 个数值字控制变频器。

步骤

  1. 连接预设选「汇川H5U (Modbus)」或「MD520 虚拟 PLC」:1507。
  2. PLC 侧写 coils 130~134（DI1~DI5），读 140~142。
  3. 写 2000H / 7310H / 1000H，读 3000H / 1001H / 1009H。

预期现象　写入 DI 位组合后 1008H 位字同步（例 130/132/133 置位 → 0b01101=13）；变频器 DO 三路回写到 140~142。

观察窗口　:5087/status 的 io 与 words、1008H / 1009H

易错点　外部写入 130~134 后内置参考程序让位 2 秒，超时会恢复覆盖。

实验 20　博途 / S7-PLCSIM 读写 ｜ 仿真 模式

目的　掌握 S7 M 区位与 MW 字通道的对应关系。

步骤

  1. 连接预设选「S7-1200/1500 仿真」:102，rack 0 / slot 1。
  2. PLC 程序写 M130.0~M134.0、读 M140.0~M142.0；数值字用 MW1000~MW1014。

预期现象　点位表通过网关校验；本机无 PLCSIM 时连接层报「ISO 握手失败」，属预期，不是地址表错误。

观察窗口　网关连接提示、地址浮框 S7 列

易错点　博途 CPU 属性要启用 PUT/GET；M 区字与位不要混用。

实验 21　GX Works2 / GX Simulator2 读写 ｜ 仿真 模式

目的　掌握三菱仿真档 Y/X 与 D 字通道。

步骤

  1. 连接预设选「三菱 GX Simulator2 仿真」，逻辑站号填通信设置实用程序里已配置的编号。
  2. PLC 程序写 Y0~Y4、读 X0~X2；数值字 D1000~D1014。

预期现象　仿真器无物理刷新，Y/X 可写；本机未配置逻辑站时连接层报 Open failed，属预期。

观察窗口　连接提示「逻辑站 N」、地址浮框三菱列

易错点　MX Component 链路里填 IP 不生效；逻辑站号必须与实用程序一致，默认 0 不是通用值。

实验 22　实物档统一 M 区 ｜ 仿真 模式

目的　理解为什么实物 PLC 无实际接线时必须用 M 区。

步骤

  1. 连接预设选三菱，把「连接目标」切到「实体 FX3U / FX5U · M 区」。
  2. 对照地址浮框，确认输入/输出列都变成 M100~/M130~ 风格，本设备用 M130~M134 / M140~M142。

预期现象　同一段速程序在实物档下点位自动换成 M 区；FX3U（GX Works2）与 FX5U（GX Works3）各需一套工程。

观察窗口　连接目标下拉、地址对照表

易错点　真实 PLC 的 X 会被 END 后物理 I/O 刷新覆盖、Y 被程序输出刷新覆盖，上位机写 X/Y 无效。

实验 23　三协议对照与外部写入让位 ｜ 仿真 模式

目的　同一控制逻辑换三种 PLC，观察点位映射与让位机制。

步骤

  1. 用同一段速逻辑分别跑 Modbus TCP / S7 / 三菱，记录各自点位。
  2. 连 :1507 时从 Node 侧直接写 coils 130~134，马上读 :5087/status。

预期现象　三种协议下变频器行为一致；/status 的 externalDi=true，2 秒内内置参考程序不覆盖外部给定。

观察窗口　三协议地址表、:5087/status.externalDi

易错点　让位只有 2 秒，连续实验要持续发帧或关掉内置参考程序。

实验 24　纯从站 :1508 发真实帧 ｜ 帧级 模式

目的　验证独立从站只响应主站帧，不自己改寄存器。

步骤

  1. 用 modbus-serial 客户端连 127.0.0.1:1508，unitId=1。
  2. 发 FC03 读 3000H、FC06 写 7310H、FC05 写 coil 140、FC15 批写 140~142、FC01 回读。
  3. 读 :5088/status。

预期现象　role=pure-slave；FC01 按字节返回 8 位，前 3 位与写入一致；masterFrames 随轮询增长。

观察窗口　:5088/status、主站日志

易错点　FC01 返回值可能多于请求位数，比较时取 slice(0,3)；2000H/7310H/1000H 会被内置主站每 200ms 覆盖。

实验 25　内置主站轮询节拍 ｜ 帧级 模式

目的　观察真实 Modbus 主站 200ms 轮询与联锁读回。

步骤

  1. 启动实验室（不要设 DT_VFD_485_MASTER=0），看主站日志。
  2. 每隔 1 秒读一次 :5088/status 的 masterFrames 与 2000H。

预期现象　日志出现「停机 → 运行 30Hz → 运行 50Hz」4s 运行 / 2s 停机循环；联锁打印 3000H / 1001H / 1009H；2000H 恒为 1 或 6，不出现 0。

观察窗口　start:lab 控制台、:5088/status

易错点　主站是演示用途，接真实 PLC 时要关掉。

实验 26　外部 PLC 独占从站 ｜ 帧级 模式

  1. 以 DT_VFD_485_MASTER=0 启动实验室。
  2. 外部 PLC（AutoShop / 博途 / GX Works2 / 实物）连 :1508 发 FC06/FC16 写、FC03 读。

预期现象　只有外部主站的帧改变从站；:5088/status 的 masterFrames 只随外部帧增长。

易错点　不关内置主站会导致两边交替覆盖 2000H/7310H，现象像「给定抖动」。

实验 27　A/B 隔离与面板跟随 B 档 ｜ 仿真 + 帧级 模式

  2. 连接预设切「MD520 485 从站 B档」127.0.0.1:1508，看面板/3D 是否跟随。

预期现象　两个 words[7310H] 互不相同；切到 :1508 后面板数值与 3D 转速跟随 B 档从站，:1507 不受影响。

实验 28　主控—观众只读跟随 ｜ 平台 模式

目的　验证 LAN 观众自动跟随、只读、零上行。

  3. 主控改参数/按 RUN，观察观众端数值与 3D。

实验 30　教学近似边界识别 ｜ 综合 模式

目的　分清哪些参数改了真有效果、哪些只存值，避免把教学模型当真机。

步骤
