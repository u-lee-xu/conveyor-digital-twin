MD520 虚拟变频器教学手册

独立设备场景 packages/md520-vfd 的参数、功能、接线与现场接入说明。生成自源码单一来源，参数变动后重新运行 generate-handbook.cjs 即可同步。

范围声明：本手册是教学子集，不是功能码全量表。08 用户手册明确「功能码、故障码的完整信息请参见 09 参数手册」，而 09 参数手册在本机多次抽取失败，因此未收录的码不猜默认值。所有物理算法（矢量控制算法、直流制动电流闭环、电机辨识）均为教学近似或不做。

1 快速上手

启动npm run start:lab 只起 Web :5201、PLC 网关 :8081、状态中继 :8082；8081 / 8082 绑回环，仿真模式连外部 PLC 仿真软件或实物 PLC。内置虚拟 PLC 不随教学交付启动。
进入设备主控本机 http://127.0.0.1:5201/，设备列表点「MD520 变频器」。观众用局域网 IP 访问，自动跟随、只读、零上行。
两种模式手动模式直接操作变频器面板；仿真模式出现 PLC 连接面板，连外部 PLC（Modbus TCP / S7 / 三菱），或用 DI/AI 端子接线控制。
初始状态默认停机 outputHz=0、命令源 F0-02=0（操作面板）、频率源 F0-03=0（数字设定）、预置频率 50Hz。

变频器是独立设备场景，与传送带分拣、自动配药完全解耦；改变频器链路不会碰到那两个已定稿场景。

2 面板与按键

真机灰白双层外壳 + 独立显示窗（6 位辅显 + 5 位主显、9 个单位灯、4 个菜单灯），10 键布局：四瓣导航（上下左右）+ 中央 OK、左侧 PRG、右侧菜单键、左下 RUN、右下 STOP/RESET、底部 MF.K。按下有下沉 / 缩放 / 压暗与回弹动画。

三级菜单与四种菜单

  • PRG 进一级参数组 → OK 进二级参数 → OK 进三级设定值；上下键改值、左右键选闪烁位、OK 保存、PRG 放弃。
  • 菜单键点按切换 basic / user / changed / fault 四种菜单，长按 600ms 切主 / 辅显示区。
  • user 菜单固定显示五种控制方式的常用设定；basic 菜单始终显示 24 个参数。

MF.K 键（面板固定功能）

MF.K 固定作正反转切换，仅在面板命令源 F0-02=0 下有效；端子 / 通信命令源下不抢方向。教学子集不再收录方向切换的档位参数。

方向切换的真值分两层：direction 是目标方向，指令下达立刻改控制字、状态字与 FWD/REV 丝印；runDirection 是实际输出方向，3D 电机 / 皮带用它。换向时先按 F0-18 把频率降到 0（仍按原方向转、只是变慢），归零后才翻转方向并按 F0-17 反向加速，不会瞬间反转。观众端通过 VFD_DIRECTION / VFD_RUN_DIRECTION 数值镜像跟随整个过程。

换向时长由加减速参数决定：减速速率 = F0-10 / F0-18，反向加速速率 = F0-10 / F0-17；斜坡标尺固定取最大频率，换向减速时取运行目标频率避免卡住。手册 30.5.4（681 页）的 F8-12 正反转死区时间 默认 0.0s，与本教学子集「归零即换向」一致，未单独收录。

5 五种控制方式

面板控制F0-02=0 / F0-03=0：RUN/STOP 控制，目标频率取 F0-08，按 F0-17/18 斜坡；MF.K 切换方向。
端子开关量F0-02=1：出厂 DI1 正转、DI2 反转，F4-11=0 两线式1；双断或双合均停机。改 F4-00~F4-04 可换端子角色，F4-11 可选两线式2 / 三线式1 / 三线式2。
多段速F0-02=1 / F0-03=6：把若干 DI 配成功能 12~15，组成段位选 FC-00~FC-07 百分比 × F0-10；运行命令仍需一个正转 / 反转端子给出。
AI 模拟量F0-03=2 / 3：AI1 -10~10V、AI2 0~10V 或 0~20mA（拨码切换），线性映射到 0~F0-10。
Modbus 通信F0-02=2 / F0-03=9：写 2000H 控制字、7310H 频率给定、1000H 百分比，读 3000H / 1001H / 1009H；FD-00~02 设波特率、格式与站号。

端子没有固定身份：DI 的角色完全由 F4-00~F4-04 当前值决定，面板按钮标题也随参数派生，避免"标签叫多段端子、出厂却是正转"的错位。

7 外部 PLC 三协议点位

PLC 程序（AutoShop / 博途 / GX Works2 / 实物 PLC）通过网关直接打开变频器 DI、读回变频器 DO，并读写 485 数值字。实物 PLC 没有实际接线，统一使用 M 区：真实 PLC 的 X 会被 END 后的物理 I/O 刷新覆盖、Y 会被程序输出刷新覆盖，上位机写 X/Y 无效。

Modbus TCP 是通用第四条路：任何支持 Modbus TCP 的 PLC 都可以用 coils 130~134 / 140~142 加 15 个数值字直接读写虚拟变频器，不必走专有协议。

外部 PLC 程序按上表点位写 DI / 读 DO，并按第 8 章通信地址读写数值字；现场实物 PLC 的 IP 在连接面板填写，不固化在程序里。内置虚拟 PLC 仅开发 / 验收使用，不参与课堂链路。

关键口径

  • 2000H 控制命令没有 0 档，写 0 无意义。取值 1~7（1 正转 / 2 反转 / 3 正转点动 / 4 反转点动 / 5 自由停机 / 6 按 F0-18 减速停机 / 7 故障复位）；0 档只存在于 7311H。
  • 1000H 是相对最大频率的百分比（-10000~+10000 对应 ±100.00%）；7310H 是按 0.01Hz 写入的通信设定频率2，单位由 FD-09、小数点与 F0-22 一致。
  • 3000H 状态：1 正转 / 2 反转 / 3 停机 / 4 电机参数辨识 / 5 故障；7044H 状态2 的 bit8~15 是故障主码。
  • 1F01H 是通信专用参数初始化（1 恢复出厂 / 4 恢复备份 / 501 备份当前），与面板参数初始化是不同接口，不要互相覆盖。

MD520_COMM 另登记 18.3 表的 1002H~1007H 监视字、100BH/100CH AI2/AI3、2003H/2004H、1F00H/1F01H、8000H 等地址，只作查表口径，不接入网关单字变量表。

10 现场接入手册

通用前提

  • 装软件的主控是唯一连 PLC 的设备；观众只读，通过中继跟随快照，不建 PLC 通道。
  • 通信恒同源：/ws/plc → 网关 :8081，/ws/relay → 中继 :8082；八个内部口全绑 127.0.0.1，对外只需放行 :5201。
  • 网关出站白名单 DT_PLC_HOSTS 默认仅回环；接实体 PLC 必须显式放行，例如 DT_PLC_HOSTS=192.168.1.50。
  • 每次启动重新签发内部链路 token；LAN 观众无法写 PLC 通道。
AutoShop / 汇川 H5U（Modbus TCP）连接预设「汇川H5U (Modbus)」127.0.0.1:502。PLC 程序写 coils 130~134 驱动 DI、读 140~142 取 DO；数值字写 2000H / 7310H / 1000H，读 3000H / 1001H / 1009H 做联锁。
博途 / S7-PLCSIM预设「S7-1200/1500 仿真」:102，rack 0 / slot 1。布尔点 M130.0~M134.0 / M140.0~M142.0，数值字 MW1000~MW1014。CPU 属性要启用 PUT/GET，否则 ISO 握手失败。
GX Works2 / GX Simulator2仿真档用 Y0~Y4 / X0~X2，数值字 D1000~D1014；实物 FX3U/FX5U 无接线统一 M130~M134 / M140~M142。链路走 MX Component 逻辑站号，填 IP 不生效。
实物 PLC在连接面板把「端口」理解为逻辑站号；站号必须与通信设置实用程序里已配置的编号一致。项目默认 0 只是历史值，不是通用值。FX3U（GX Works2）与 FX5U（GX Works3）各维护一套工程。

现象检查

无法写入频率F0-03=0 时地址对应 F0-08；F0-03=9 时地址应为 1000H 或 7310H；检查终端电阻。

12 外部 PLC 的 DI/AI 端子控制

除了第 7、8 章的通信控制（F0-02=2、F0-03=9），现场更常见的是端子控制：PLC 的数字量输出接变频器 DI 端子决定运行、方向与多段速，模拟量输出接 AI 端子给频率。两种方式都由外部 PLC 编程软件的 simulator 或实物 PLC 提供，教学交付不启动任何内置虚拟 PLC。

  • 端子接线见第 6 章控制回路图：DI1~DI5、AI1/AI2、AO1、DO1/FM、485+/485-、STO1。
  • 切换 F0-02 / F0-03 前先停机，这两个参数属「停机更改」。
  • 两线式1 下正转 / 反转两路同时有效或同时断开均为停机，属禁止态。
  • 现场 IP 在连接面板按实际网络填写；接实体 PLC 需在 DT_PLC_HOSTS 显式放行。
