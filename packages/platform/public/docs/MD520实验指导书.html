MD520 虚拟变频器实验指导书

共 30 个实验，分 6 类。每个实验给出目的、操作步骤、预期现象（带具体数值）、观察窗口与易错点。参数默认值由 generate-lab-guide.cjs 从 md520Spec.ts 读取，参数变动后重跑脚本即同步。

教学边界：变频器是教学子集，不是真机。矢量控制、直流制动电流闭环、电机辨识均不做；24 个教学参数围绕五种控制方式，改值即有对应现象或显示变化。仿真模式一律连接外部 PLC 编程软件的 simulator 或实物 PLC：用 Modbus TCP 通信控制（F0-02=2 / F0-03=9），或用 DI/AI 端子接线控制（F0-02=1）。内置虚拟 PLC 不是教学交付内容，只在开发 / 验收模式下启用。

开始之前：先认清面板和模式

实验步骤里写的 PRG / OK 是按键代号，面板键帽上印的却是符号（比如 PRG 键印的是 ↩）。把鼠标移到按键上，悬停提示会同时显示代号、符号和中文名，例如「PRG ↩ · 编程/返回键」。下面三张表先看一遍，后面 30 个实验就能对上号。

1　两种运行模式：实验里的「手动 / 仿真」是什么意思

模式是什么怎么进入
手动不连 PLC，直接用面板按键操作变频器。设备列表进入后默认就是这一档，入门实验都在这里做。进入 MD520 场景后，左上面板「运行模式」选中「手动」即可，无需连接面板、无需 PLC。
仿真由外部 PLC 编程软件的 simulator 或实物 PLC 控制变频器，面板下方出现 DI/AI/485 教学信号区。在「运行模式」点「仿真」，再用连接面板连外部 PLC；教学交付不启动任何内置虚拟 PLC。

3　三级菜单是什么：L1 组 → L2 参数 → L3 设定值

「三级菜单读写参数」不是在三级子菜单里翻来翻去，而是改一个参数的三个步骤：先选参数所在的组（L1），再选具体参数码（L2），最后改这个参数的数值（L3）。每层按 OK 进一层、按 PRG 退一层。

层级怎么进屏幕上看什么能做什么
L1 参数组待机主显下按 PRG辅显显示参数组字母，如 F0UP/DOWN 切组，OK 进 L2，PRG 退回主显
L2 参数L1 下按 OK主显显示参数码，如 F0-08UP/DOWN 选参数，OK 进 L3，PRG 退回 L1
L3 设定值L2 下按 OK主显显示数值并有某一位闪烁，如 50.00LEFT/RIGHT 选闪烁位，UP/DOWN 改数值，OK 保存退到 L2，PRG 放弃修改

A 类　面板与菜单（5 项）

实验 1　三级菜单读写参数 ｜ 手动 模式

目的　学会用面板找到并修改一个参数。三级菜单就是 L1 参数组 → L2 参数码 → L3 设定值三层，进一层按 OK、退一层按 PRG。

步骤

  1. 设备列表点「MD520 变频器」进入，左上面板「运行模式」选中「手动」。手动＝不接 PLC，直接用面板按键操作；这是进入后的默认档，本实验不用连任何 PLC。
  2. 面板左上那颗印着 ↩ 的键就是 PRG 键（鼠标悬停显示「PRG ↩ · 编程/返回键」）。按它进 L1，用 △ 递增键切到 F0 组，按中央 OK 进 L2，用 △ 选到 F0-08，再按 OK 进 L3。
  3. L3 主显是 50.00 且有一位在闪：◀▶ 左右键选闪烁位，△▽ 上下键把预置频率改成 30.00Hz。
  4. 按 OK 保存（自动跳到下一个参数）；再改一次但按 PRG 放弃，对比保存和放弃两次的结果。

预期现象　保存后主显 30.00、状态行显示下一个参数码；按 PRG 放弃则回到修改前的值。参数标「停机更改」时运行中改不了。

观察窗口　主/辅显示区、闪烁位、状态行 L1/L2/L3

易错点　闪烁位用 ◀▶ 左右键、数值用 △▽ 上下键；右侧印 ⌂ 的 MENU 键是切四种菜单，不是返回键，别按它退出。

实验 2　四种菜单与主辅显示区 ｜ 手动 模式

目的　区分 basic / user / changed / fault 四种菜单，掌握菜单键点按与长按。

步骤

  1. 点按菜单键循环四种菜单，观察 basic 与 user 的参数条数。
  2. 先改几个参数，再切到 changed，确认只列出改过出厂值的参数。
  3. 长按菜单键 600ms 切主/辅显示区；切到 fault 看故障列表。

预期现象　basic 显示全部 24 个参数；user 固定显示五种控制的常用设定；changed 只列偏离默认值的码；fault 显示 6 条教学故障码。

观察窗口　辅显示区代码、菜单指示灯

易错点　长按必须超过 600ms，短按只切菜单。

实验 3　面板 RUN/STOP 与预置频率 ｜ 手动 模式

目的　理解面板命令源与加减速斜坡，建立频率与 3D 转速的对应关系。

步骤

  1. 确认 F0-02=0（操作面板）、F0-03=0（数字设定）、F0-08 = 50Hz、F0-17 = 20s。
  2. 按 RUN，每 1 秒记录一次输出频率；到稳态后按 STOP。
  3. 把 F0-17 改成 2s，复位后重做一次。

预期现象　默认 20s 斜坡下 1 秒约升 2.5Hz、约 20 秒到 50Hz；改成 2s 后 1 秒约升 25Hz。3D 风扇、双滚筒、皮带条纹与频率牌同步。

观察窗口　主显输出频率、3D 风扇转速、皮带条纹位移

易错点　斜坡时间是从 0 到最大频率的时间，不是到目标频率的时间。

实验 4　端子命令方式四档总览 ｜ 手动 模式

目的　认识 F4-11 四种端子命令方式，理解端子角色由参数而非 DI 编号决定。

步骤

  1. 保持 F0-02=0，先看面板出厂默认：DI1 功能 1 正转、DI2 功能 2 反转、F4-11=0 两线式1。
  2. 把 F4-11 依次切到 0/1/2/3，每档到教学信号区看 DI 按钮标题是否随 F4-xx 派生。
  3. 对照教学手册第 1.1.1.3 节四种方式的真值表。

预期现象　两线式1 双断/双合停机、单合正转或反转；两线式2 一端子运行一端子方向；三线式 需功能 3 端子常闭且启动取上升沿。面板按钮标题随功能码变化，不再是固定文案。

观察窗口　F4-11 当前档位、DI 按钮 title、面板 FWD/REV 丝印

易错点　F4-11 与 F4-00~F4-04 配合才决定行为；只改命令方式不改功能码可能得不到预期端子。

实验 5　改端子功能：交换方向与多段端子 ｜ 手动 模式

目的　掌握 F4-00~F4-04 决定 DI 角色，验证端子没有写死的身份。

步骤

  1. 把 F4-00 从 1（正转）改成 2（反转）、F4-01 从 2 改成 1（正转），F0-02=1 端子命令源。
  2. 只合 DI1，看方向；再改成只合 DI2，看方向。
  3. 把 F4-00 改成 12（多段指令端子1），回面板看 DI1 标题变化。

预期现象　交换功能码后 DI1 驱动反转、DI2 驱动正转，证明方向不绑 DI 编号；改成 12 后 DI1 不再单独给运行命令，标题变成「多段指令端子1」。

观察窗口　DI 按钮 title、FWD/REV 丝印、3D 转向

易错点　改端子功能前先停机；多段端子只给段位，运行命令要靠另一个配成正转/反转的端子。

B 类　给定与频率（7 项）

实验 6　四种给定切换 ｜ 手动 + 仿真 模式

目的　分辨命令源 F0-02 与频率源 F0-03，理解谁能抢运行权。

步骤

  1. 依次设 F0-02=0/1/2，观察面板 RUN 是否生效。
  2. 固定 F0-02=0，依次设 F0-03=0/2/3/6/9，观察目标频率从哪来。

预期现象　F0-02=2（通信）时面板 RUN/STOP 不再抢运行权，由 2000H 控制字决定；F0-03=6 走 DI 多段速、=9 走通信给定。

观察窗口　485 状态行 2000H 命令、运行/停机徽标

易错点　命令源与频率源是两个独立参数，不要一起改。

实验 7　DI 多段速 8 段 ｜ 手动 模式

目的　掌握 DI1~DI3 三位二进制选段 + DI4 运行使能。

步骤

  1. 设 F0-02=1、F0-03=6；教学信号区按 DI4 使能。
  2. 按 DI1~DI3 组合出 000~111，逐段记录「段N xxHz」。

预期现象　默认 FC 百分比 0/20/40/60/80/100/70/50% 对应 0/10/20/30/40/50/35/25Hz（F0-10=50Hz）。

观察窗口　段速标签、面板输出频率、3D 转速

易错点　DI4 不使能时不会运行；DI5 是高速脉冲输入，不参与选段。

实验 8　FC 段速成为真值 ｜ 手动 模式

目的　验证段速不是硬编码 Hz 表，而是 FC 百分比 × F0-10。

步骤

  1. 停在段 2（DI2 单独 ON），记下频率。
  2. 把 FC-02 从 40% 改成 10%，保存后回到监控页。
  3. 再把 F0-10 从 50 改成 60，看同一段的变化。

预期现象　FC-02=40% → 20Hz；改成 10% → 5Hz；F0-10=60 后 10% → 6Hz。面板、PLC 参考程序、3D 读数同源。

观察窗口　段速标签、1008H DI 位字、3D

易错点　FC 单位是相对最大频率的百分比，不是 Hz。

实验 9　AI 模拟量给定 ｜ 手动 模式

目的　理解 AI1 双极性电压、AI2 电压/电流拨码与频率映射。

步骤

  1. 设 F0-03=2，拖 AI1 从 0 到 5.0V，记录输出频率；再拖到 -5.0V。
  2. 设 F0-03=3，用「0~10V / 0~20mA」按钮切档，拖 AI2 到 5.0V 或 10mA。

预期现象　目标频率 = |AI| / 满量程 × F0-10：AI1 5.0V → 25Hz（取绝对值）；AI2 5.0V / 10mA → 25Hz。100AH 数值镜像同步。

观察窗口　AI1/AI2 滑块读数、100AH

易错点　AI1 是 -10~10V 双极性，负电压给的是频率绝对值；方向另由 FWD/REV 决定。

实验 10　外部 PLC 通信给定与状态回读 ｜ 仿真 模式

目的　用外部 PLC 的控制字与频率给定控制变频器，并读懂回读状态。

步骤

  1. 设 F0-02=2（通信命令源）、F0-03=9（通信频率源），在连接面板连外部 PLC 仿真软件或实物 PLC（Modbus TCP :502 / S7 :102 / 三菱）。
  2. PLC 程序写 2000H=1（正转）、7310H=3000（30.00Hz）、1000H=6000（60.00%）。
  3. 读 3000H、1001H、1009H、7044H，对照面板主显与 3D 转速。

预期现象　输出 30.00Hz；3000H=1（正转）、1001H=3000（0.01Hz）、1009H 的 DO1 位为 1；停机写 2000H=6 后 3000H=3。

观察窗口　面板 485 只读状态行、连接面板提示、PLC 在线表

易错点　2000H 没有 0 档，写 0 无意义；7310H 是 0.01Hz，1000H 是 ±100.00% 百分比。

实验 11　固定斜坡与频率上限 ｜ 手动 模式

目的　用 F0-17/F0-18 设定加减速时间，理解 F0-10 是输出频率上限。

步骤

  1. 默认 F0-17=20s、F0-18=20s、F0-10=50，RUN 后记录 1 秒爬升量。
  2. 把 F0-17 改成 10s，停机后重新 RUN 再记录 1 秒爬升量。
  3. 把 F0-10 从 50 改成 30，观察主显上限。

预期现象　默认 1 秒爬升 2.5Hz；F0-17=10s 后 1 秒爬升 5Hz；F0-10=30 时主显不超过 30Hz。斜坡只由 F0-17/F0-18 决定，没有基准档位切换。

观察窗口　主显输出频率、3D 转速

易错点　F0-17/F0-18 是固定斜坡时间，不再按基准档换算；F0-10 是上限，不是给定值。

实验 12　五种控制方式总览 ｜ 手动 模式

目的　用 F0-02 / F0-03 组合切换面板、端子、多段速、模拟量与通信控制。

步骤

  1. F0-02=0、F0-03=0 走面板：按键启停，MF.K 切方向。
  2. F0-02=1 走端子：由 F4-11 与 F4-00~F4-04 决定运行命令；F0-03=6 时由功能 12~15 选 FC 段。
  3. F0-03=2/3 走 AI1/AI2 模拟量给定；F0-02=2、F0-03=9 走 Modbus TCP 通信给定。

预期现象　面板档由按键决定方向与频率；端子档由 F4-11 与端子功能码决定；多段速由功能 12~15 选段；模拟量取 |AI| / 满量程 × F0-10；通信档由 2000H/7310H 决定。段 2（40%）在 F0-10=60 时为 24Hz。

观察窗口　F0-02 / F0-03 当前值、面板 RUN/FWD/REV、主显与 3D

易错点　F0-02 / F0-03 属停机更改参数，运行中切换会被拒绝或延后生效；教学子集没有矢量控制档位。

C 类　停机方向与状态（6 项）

实验 13　减速停机与固定斜坡标尺 ｜ 手动 模式

目的　理解教学子集的停机行为：按 F0-18 减速，标尺固定取 F0-10。

步骤

  1. RUN 到 50Hz 后按 STOP，每 0.5 秒记录一次频率。
  2. 把 F0-18 从 20s 改成 2s 重做一次。
  3. 把 F0-10 从 50 改成 60，观察斜坡速率变化。

预期现象　默认 20s 减速下 0.5 秒约剩 48.75Hz；改成 2s 后约剩 43.75Hz；F0-10 加大后同样减速率更快。没有自由停机与直流制动段。

观察窗口　主显输出频率、3D 是否逐渐停转

易错点　斜坡标尺是 F0-10 最大频率，不是目标频率；教学子集不实现 F6 停机方式与直流制动。

实验 14　两线式1 的禁止态与方向 ｜ 手动 + 仿真 模式

目的　验证双断/双合停机与单端子正反转，符合手册真值表。

步骤

  1. F0-02=1、F4-11=0，DI1 正转、DI2 反转。
  2. 依次试：全断、只合 DI1、只合 DI2、双合，记录运行状态与方向。

预期现象　全断与双合都停机；只合 DI1 正转；只合 DI2 反转。双合属禁止态，不允许当成反转指令。

观察窗口　FWD/REV 丝印、1008H DI 位字、3D 转向

易错点　与电机正反转场景的互锁同类：两路同时有效优先保持安全态。

实验 15　三线式启动上升沿 ｜ 手动 + 仿真 模式

目的　理解三线式需要常闭允许端子，且启动信号取上升沿。

步骤

  1. 设 F4-11=2、F4-02=3 三线控制，DI1 仍是正转、DI2 反转。
  2. 只合 DI1（允许端子未合），观察。
  3. 先合 DI3 允许，再合 DI1，记录；保持 DI3 与 DI1 闭合，连续采样。

预期现象　允许端子未合时一律停机；允许闭合后 DI1 上升沿才启动正转；持续闭合不重复触发，命令保持。

观察窗口　__dtVfdDrive 或直接看主显与 DI 位字

易错点　三线式是脉冲触发，不是电平保持；松开允许端子立即停机。

实验 16　MF.K 固定方向与 3D 换向过程 ｜ 手动 模式

目的　掌握 MF.K 固定作面板命令源下的方向切换，观察先减速再反向加速。

步骤

  1. F0-02=0，RUN 到有输出，把 F0-17 / F0-18 改小到 2s。
  2. 按 MF.K，立刻看 __dtVfdDrive：targetDirection 变 -1、direction 仍是 1、reversing=true。
  3. 采样直到 hz 归零、direction 翻转，再间隔 0.5 秒采两次 fanAngle / beltPhase。

预期现象　换向期间仍按原方向减速；归零后才翻转并反向加速；风扇角差由负变正（实测 -0.83 → +1.21），皮带相位由正变负（+0.023 → -0.034）。

观察窗口　__dtVfdDrive.direction / targetDirection / reversing / hz / fanAngle / beltPhase

易错点　面板丝印显示目标方向，3D 用实际输出方向 runDirection；别在减速阶段就断言反向。

实验 17　正反转切换：减速到零再反向加速 ｜ 手动 模式

目的　验证换向不是瞬间反转，而是先按 F0-18 减速到 0、翻转输出方向、再按 F0-17 反向加速。

步骤

  1. F0-02=0，RUN 到有输出（建议先把 F0-18 / F0-17 改小到 2s 缩短等待）。
  2. 按 MF.K，立刻看 __dtVfdDrive：targetDirection 变 -1、direction 仍是 1、reversing=true、hz 持续下降。
  3. 连续采样直到 hz 归零、direction 翻成 -1，再看 hz 反向上升；随后间隔 0.5 秒采两次 fanAngle / beltPhase。

预期现象　换向期间电机仍按原方向转、只是越来越慢（减速阶段风扇角差仍为负）；频率归零后 direction 才由 1 变 -1 并反向加速；风扇角差由负变正（实测 -0.83 → +1.21），皮带相位由正变负（+0.023 → -0.034）；FWD/REV 丝印指令下达即互换。

观察窗口　__dtVfdDrive.direction / targetDirection / reversing / hz / fanAngle / beltPhase、FWD/REV 灯

易错点　别在减速阶段就断言反向：那时 direction 还是 1；面板丝印显示的是目标方向，3D 用的是实际输出方向 runDirection。

实验 18　DO 状态、故障与只读监视量 ｜ 手动 + 仿真 模式

目的　读懂 DO1/FM/RELAY、3000H 状态与输出电流/功率监视量。

步骤

  1. RUN 到稳态，看 DO1（运行中）、FM（频率到达）亮，RELAY 灭。
  2. 制造故障后看 RELAY 与 3000H=5，再用 STOP/RESET 或 2000H=7 复位。
  3. 观察满载监视量；改变负载率（调目标频率），看电流/功率随频率线性变化。

预期现象　满载显示约 9.00A / 3.70kW；半速约 6.15A / 1.85kW；停机后监视量归零。

观察窗口　DO 只读徽标、data-dt-vfd-monitor、3000H / 7044H

易错点　这些监视量是固定系数近似（空载 15% 电流 + 负载率线性），不依赖 F1 铭牌参数，不是真实电机模型。

实验 19　AutoShop / Modbus TCP 读写 ｜ 仿真 模式

目的　用外部 PLC 程序通过 coils 与 15 个数值字控制变频器。

步骤

  1. 连接预设选「PLC 仿真软件 (Modbus TCP :502)」或「汇川 H5U」，现场实物 PLC 请在连接面板填实际 IP。
  2. PLC 程序写 coils 130~134（DI1~DI5），读 140~142。
  3. 写 2000H / 7310H / 1000H，读 3000H / 1001H / 1009H。

预期现象　写入 DI 位组合后 1008H 位字同步（例 130/132/133 置位 → 0b01101=13）；变频器 DO 三路回写到 140~142。

观察窗口　网关连接提示、1008H / 1009H、PLC 在线表

易错点　coils 130~134 是 PLC → 变频器的输入，140~142 是回读输出；方向不要写反。

实验 20　博途 / S7-PLCSIM 读写 ｜ 仿真 模式

目的　掌握 S7 M 区位与 MW 字通道的对应关系。

步骤

  1. 连接预设选「S7-1200/1500 仿真」:102，rack 0 / slot 1。
  2. PLC 程序写 M130.0~M134.0、读 M140.0~M142.0；数值字用 MW1000~MW1014。

预期现象　点位表通过网关校验；本机无 PLCSIM 时连接层报「ISO 握手失败」，属预期，不是地址表错误。

观察窗口　网关连接提示、地址浮框 S7 列

易错点　博途 CPU 属性要启用 PUT/GET；M 区字与位不要混用。

实验 21　GX Works2 / GX Simulator2 读写 ｜ 仿真 模式

目的　掌握三菱仿真档 Y/X 与 D 字通道。

步骤

  1. 连接预设选「三菱 GX Simulator2 仿真」，逻辑站号填通信设置实用程序里已配置的编号。
  2. PLC 程序写 Y0~Y4、读 X0~X2；数值字 D1000~D1014。

预期现象　仿真器无物理刷新，Y/X 可写；本机未配置逻辑站时连接层报 Open failed，属预期。

实验 22　实物档统一 M 区 ｜ 仿真 模式

目的　理解为什么实物 PLC 无实际接线时必须用 M 区。

步骤

  1. 连接预设选三菱，把「连接目标」切到「实体 FX3U / FX5U · M 区」。
  2. 对照地址浮框，确认输入/输出列都变成 M100~/M130~ 风格，本设备用 M130~M134 / M140~M142。

预期现象　同一段速程序在实物档下点位自动换成 M 区；FX3U（GX Works2）与 FX5U（GX Works3）各需一套工程。

观察窗口　连接目标下拉、地址对照表

实验 23　三协议对照与通信 / 端子切换 ｜ 仿真 模式

目的　同一控制逻辑换三种外部 PLC，并切换通信给定与 DI/AI 端子给定。

步骤

  1. 用同一段速逻辑分别跑 Modbus TCP / S7 / 三菱，记录各自点位。
  2. 把 F0-02 从 2（通信）改到 1（端子）、F0-03 从 9 改到 2（AI1），观察给定来源切换。

预期现象　三种协议下变频器行为一致；切到端子给定后通信控制字不再抢运行权，频率由 AI1 电压决定。

观察窗口　三协议地址表、F0-02 / F0-03 当前值、主显输出频率

易错点　切换给定源前先停机；运行中改 F0-02 / F0-03 属停机更改参数。

E 类　DI/AI 端子控制（4 项）

实验 24　端子运行指令 DI1 / DI2 ｜ 仿真 模式

目的　掌握 F0-02=1 时由外部 PLC 数字量输出决定运行与方向。

步骤

  1. 设 F0-02=1（端子运行指令），连接外部 PLC 仿真软件或实物 PLC。
  2. PLC 数字量输出接 DI1（正转）与 DI2（反转），依次置位观察。
  3. 对照 1008H DI 位字与面板 RUN / FWD / REV。

预期现象　DI1=1 且 DI2=0 时正转加速；DI2=1 且 DI1=0 时反转；双断或双合停机。功能码可改，端子角色不固定。

观察窗口　1008H DI 位字、FWD/REV 丝印、3D 风扇转速

易错点　两路方向信号同时得电属禁止态，不要当成反转指令。

实验 25　AI1 / AI2 模拟量频率给定 ｜ 仿真 模式

目的　用外部 PLC 模拟量输出接 AI 端子给频率。

步骤

  1. 设 F0-03=2（AI1）或 3（AI2），F0-02 保持 1 让端子决定运行。
  2. PLC 模拟量输出给 0~10V / 0~20mA，或在教学面板拖 AI1 / AI2 滑块模拟现场信号。
  3. 记录 5.0V / 10mA 对应的输出频率并对照 100AH 数值镜像。

预期现象　目标频率 = |AI| / 满量程 × F0-10：AI1 5.0V → 25Hz（取绝对值）；AI2 5.0V / 10mA → 25Hz；100AH 同步。

观察窗口　AI1/AI2 读数、100AH、主显输出频率

易错点　AI1 是 -10~10V 双极性，负电压给频率绝对值；方向由 FWD/REV 端子决定。

实验 26　DI 多段速与 FC 百分比 ｜ 仿真 模式

目的　用 DI1~DI3 组合选择段速，理解 FC-00~FC-07 是相对最大频率的百分比。

步骤

  1. 设 F0-03=6，把 DI1~DI3 的 F4-00~F4-02 改成 12/13/14，另留 DI4=1 正转给运行；PLC 组合 DI1~DI3 选段 0~7。
  2. 把 FC-02 从 40% 改成 10%，再改 F0-10 从 50 到 60，观察同一段频率变化。

预期现象　默认 FC-02=40% → 20Hz；改成 10% → 5Hz；F0-10=60 后 10% → 6Hz。面板、PLC 程序、3D 读数同源。

观察窗口　段速标签、1008H DI 位字、3D

易错点　FC 单位是相对最大频率的百分比，不是 Hz。

实验 27　通信给定与端子给定对照 ｜ 仿真 模式

目的　分清 F0-02 / F0-03 的给定来源，避免两个控制源抢运行权。

步骤

  1. 先设 F0-02=2、F0-03=9 用 Modbus TCP 通信给定跑一次。
  2. 再设 F0-02=1、F0-03=2 用默认 DI1 正转 + AI1 端子给定跑一次，对比运行权与频率来源。
  3. 每次切换前先停机，切换后读 3000H / 1001H / 1009H 与面板主显。

预期现象　通信档由 2000H/7310H 决定运行与频率；端子档由 DI1 正转 / AI1 决定，通信控制字不再抢运行权；两档的 DO 回读一致。

观察窗口　F0-02 / F0-03 当前值、3000H / 1001H、面板主显

易错点　F0-02 / F0-03 属停机更改参数；运行中切换会被拒绝或延后生效。
